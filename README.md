## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/gaurigulhane/gauri-portfolio.git
cd gauri-portfolio
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run locally

```bash
npm run dev
```

👉 Open: `http://localhost:5173`
